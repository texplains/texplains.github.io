2. Worum es geht

ShortsBot ist ein privates Programm, das nur auf dem Computer des Verantwortlichen läuft. Es erstellt kurze Videos und lädt sie über die offizielle YouTube Data API v3 auf den eigenen YouTube-Kanal TExplains hoch. ShortsBot wird keinen anderen Personen angeboten und greift nicht auf Daten anderer Nutzer zu.

3. Nutzung von Google- und YouTube-Daten

ShortsBot verwendet YouTube API Services. Mit der Nutzung gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung.

Welche Daten werden genutzt?

  • Name und ID des eigenen YouTube-Kanals – um sicherzustellen, dass nur auf den richtigen Kanal hochgeladen wird.
  • Die vom Verantwortlichen selbst erstellten Videos samt Titel, Beschreibung und Tags – zum Hochladen.
  • Upload-, Verarbeitungs- und Sichtbarkeitsstatus der eigenen Videos – um geplante Veröffentlichungen zu überwachen.
  • Ein OAuth-Zugriffstoken – um im Namen des eigenen Kanals handeln zu dürfen.

Es werden keine Daten anderer YouTube-Nutzer, Kommentare, Abonnenten- oder Zuschauerdaten abgerufen. ShortsBot löscht keine Videos.

Speicherung und Sicherheit

Alle Daten werden ausschließlich lokal auf dem Computer des Verantwortlichen gespeichert. Das Zugriffstoken wird mit der Windows-Datenschutzschnittstelle (DPAPI) verschlüsselt und ist nur für das Windows-Benutzerkonto des Verantwortlichen lesbar. Es gibt keinen Server, auf den Daten übertragen werden.

Weitergabe

Daten aus Google- bzw. YouTube-Konten werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung genutzt. Für die Erstellung der Videoinhalte (Skripte, Bilder, Sprachausgabe) kann ShortsBot KI-Dienste wie Anthropic (Claude), OpenAI, ElevenLabs oder Replicate nutzen. Diese erhalten nur Skripttexte und Bildbeschreibungen, jedoch keine Daten aus Google- oder YouTube-Konten.

Die Nutzung und Übertragung von Informationen, die ShortsBot über Google APIs erhält, entspricht der Richtlinie zu Nutzerdaten für Google API-Dienste, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

Löschung und Widerruf

Der Zugriff von ShortsBot kann jederzeit in den Google-Kontoeinstellungen unter https://myaccount.google.com/permissions widerrufen werden. Beim Trennen der Verbindung in ShortsBot wird das Zugriffstoken sofort gelöscht; die übrigen lokalen Daten (Upload-Verlauf mit Video-IDs) werden gelöscht, wenn ShortsBot entfernt wird. Auf Anfrage per E-Mail werden gespeicherte Daten innerhalb von 30 Tagen gelöscht.

2. About ShortsBot

ShortsBot is a private application that runs only on the controller's own computer. It creates short videos and uploads them via the official YouTube Data API v3 to the controller's own YouTube channel TExplains. It is not offered to any other person and does not access other users' data.

3. Use of Google and YouTube data

ShortsBot uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply.

  • Data accessed: the name and ID of the owner's channel; the owner's own videos with title, description and tags; upload, processing and privacy status of those videos; an OAuth access token.
  • Purpose: uploading the owner's own videos, scheduling their publication and verifying that only the correct channel is used. No data of other YouTube users, comments, subscriber or viewer data are accessed. ShortsBot never deletes videos.
  • Storage: all data is stored only locally on the owner's computer. The access token is encrypted with Windows DPAPI. There is no server to which data is transmitted.
  • Sharing: Google/YouTube user data is not shared with third parties, not sold and not used for advertising. AI services (such as Anthropic, OpenAI, ElevenLabs or Replicate) may be used to create video content; they receive only script texts and image descriptions, never Google or YouTube user data.

ShortsBot's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion: access can be revoked at any time via https://myaccount.google.com/permissions. Disconnecting ShortsBot deletes the access token immediately; the remaining local data (upload history with video IDs) is deleted when ShortsBot is removed. Upon request by email, stored data will be deleted within 30 days.

4. This website

This website is hosted on GitHub Pages (GitHub, Inc., USA). GitHub processes technically necessary data such as IP address, date/time and browser information to deliver the page and ensure security. This website uses no cookies, no analytics or tracking tools and no embedded third-party content.
