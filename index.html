Was ist ShortsBot?

ShortsBot ist ein Programm, das ausschließlich auf dem privaten Computer des Kanalbetreibers läuft. Es erstellt kurze Videos (YouTube Shorts) und lädt sie über die offizielle YouTube Data API v3 auf den eigenen YouTube-Kanal TExplains hoch.

  • ShortsBot wird nur vom Kanalbetreiber selbst genutzt und ist kein öffentlicher Dienst.
  • Es greift ausschließlich auf den eigenen Kanal zu – nicht auf Daten anderer Nutzer.
  • Es werden keine Videos gelöscht und keine Kommentare, Abonnenten- oder Zuschauerdaten verarbeitet.

What is ShortsBot? (English)

ShortsBot is a private tool that runs only on the channel owner's own computer. It creates short videos (YouTube Shorts) and uploads them via the official YouTube Data API v3 to the owner's own YouTube channel TExplains. It is not offered to other users, accesses only the owner's own channel, and does not delete videos or process viewer data.
